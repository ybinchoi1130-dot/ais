[깃 작업 취소]
HEAD란 현재 사용 중인 브랜치의 선두 부분(최신 커밋 부분)을 가리킨다.
틸드(~, 물결기호)와 캐럿(^, 삽입기호)을 사용하여 현재의 커밋(HEAD)으로부터 특정 커밋의 위치를 가리킬 수 있다.
HEAD 뒤에 틸드(~)를 붙여 몇 세대 앞의 커밋을 지정할 수있다.
캐럿(^)을 브랜치 병합에서 원본이 여럿 있는 경우에 몇 번째 원본인지 지정할 수 있다.

HEAD : 현재위치
HEAD~1 or HEAD^ : HEAD 바로 이전 위치
HEAD~2 or HEAD~1^1 : HEAD~1의 이전 위치
HEAD~3 : HEAD~2의 이전 위치


리셋옵션
reset option: --hard, --soft, --mixed(default)

-----------------------------------------------------------------
옵션: --mixed(default)
-----------------------------------------------------------------
커밋(commit) 취소, add 취소
git reset HEAD^
GIT RESET --mixed HEAD^

add 취소
git reset HEAD
git reset --mixed HEAD

수정 취소
git restore filename

-----------------------------------------------------------------
옵션: --soft
-----------------------------------------------------------------
커밋(commit) 취소
git reset --soft HEAD^

add 취소
git restore --staged filename

수정취소
git restore filename


-----------------------------------------------------------------
옵션: --hard
-----------------------------------------------------------------
수정되기 전 상태(원본 유지)
커밋(commit) 취소, add 취소, 수정 취소
git reset --hard HEAD^


-----------------------------------------------------------------
병합취소(Branch Cancel)
-----------------------------------------------------------------
git reset --merge ORIG_HEAD
git reset --hard ORGI_HEAD
